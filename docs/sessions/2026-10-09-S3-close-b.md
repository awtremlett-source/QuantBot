## Diagnosis

1. **The pipe, not the data.** The recorder wrote raw bars every hour, but
   nothing scheduled ran the front door. The clean store therefore stopped on
   2 Oct, and every census after that read stale data.
2. **The labels counted repeats.** `record_now._update_minute_labels` ran on
   every catch-up, and each run counted as a pass, even over the same bars. That
   is how 86 names were promoted on 5 Oct.
3. **The status page judged the old trigger.** A run 20 minutes late counted as
   "on the hour", and it could not tell one expected catch-up from a re-based
   series.
4. **"Daily digest" named a thing qb2 did not have.** v1's digest lives in the
   frozen monitors/.

## Decisions, each with its enforcer

| Decision | Enforcer |
|---|---|
| The after-hours step runs AFTER sampling and every fetch | `test_cleaning_comes_after_the_sampling_and_every_fetch` |
| Once per finished day (all markets closed); a RED clean is retried only after hours | `test_the_step_runs_once_per_finished_day`, `test_a_red_clean_is_retried_after_hours_only` |
| Catch up every day not yet cleaned | `test_every_trading_day_not_yet_cleaned_is_caught_up` |
| Idempotent | `test_running_the_step_twice_changes_nothing` |
| Half-written raw file: skipped, named, retried | `test_a_half_written_raw_file_is_skipped_and_named` |
| RED when below a gate, or older than the last finished session; holidays are not gaps | the stale and calendar tests in `test_qt13b_clean_step.py` |
| The status page counts a session only once overdue (10:00 next weekday) | `test_tonights_session_is_not_overdue_until_the_next_morning`, `test_a_step_that_stops_running_goes_red_within_one_trading_day` |
| A label pass counts only on newer bars | `test_the_5_oct_promotion_on_unchanged_data_does_not_promote` |
| Runs on :00; one catch-up named; DRIFT flagged; missed :00 listed | four status_push tests |
| A step failure is a complaint, never a crash | `test_a_failing_step_is_a_complaint_not_a_crash` |

Each was watched red first. Some were red against the old code: the label rule
promoted, record_now never cleaned, and status_push could not say DRIFT. Others
were red against a planted mutant that was then restored byte for byte: no hash
skip, no read guard, weekdays instead of the calendar, staleness ignored.
