**What the reviews did not cover.** The reviewer was a fresh agent with its own copy of the repo, not a
separate app session: the app refuses to start sessions from an automated turn. The fixes made after the
second review have tests and disable-proofs but no third independent read, on the rule against buying
another pass. Tools were available to the two proof sessions; their records show none were used.

**The second review's findings.** Closed since: a fake revert message passing the hook (a revert must now
name a commit in history), a seam naming a folder, the door reading the working folder instead of what is
staged, reverts and merges being refused, a moved note jamming the ledger, a respelled note, names inside
strings counting as tests. Still open and stated on the line itself: junk words pass the word counts; a
rename closes a seam item; a commit can name an item with no real connection beyond the file list; the
wall tests catch plain routes only; a revert naming a real commit is not checked to undo it.

**One history note.** The first version was one local commit (c31bbac) that was never pushed. It was
replaced once, because its owed-count ceiling of 84 rested on claims the review had refuted, and the ratchet
would otherwise hold that false number for good. If a later review finds a false ENFORCED claim, correcting
it raises the owed count, which gate 5 refuses: that comes to the operator.
